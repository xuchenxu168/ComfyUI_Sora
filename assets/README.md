# Assets 目录说明

## 📁 目录用途

此目录用于存放 README.md 中引用的图片资源。

---

## 📋 需要的文件

请将以下文件放入此目录：

### 1. 微信二维码
- **文件名**: `wechat_qrcode.png`
- **用途**: 用户添加微信联系
- **建议尺寸**: 400x400 像素或更大
- **格式**: PNG（推荐）或 JPG

### 2. 微信收款二维码
- **文件名**: `wechat_pay_qrcode.png`
- **用途**: 用户赞赏支持
- **建议尺寸**: 400x400 像素或更大
- **格式**: PNG（推荐）或 JPG

---

## 📝 使用说明

1. **准备二维码图片**
   - 微信个人二维码（用于添加好友）
   - 微信收款二维码（用于接收赞赏）

2. **重命名文件**
   - 将微信二维码重命名为 `wechat_qrcode.png`
   - 将收款二维码重命名为 `wechat_pay_qrcode.png`

3. **放入此目录**
   - 将两个文件复制到 `custom_nodes/ComfyUI_Sora/assets/` 目录

4. **验证**
   - 在 GitHub 上查看 README.md，确认二维码正确显示

---

## ✅ 文件清单

- [ ] `wechat_qrcode.png` - 微信二维码
- [ ] `wechat_pay_qrcode.png` - 微信收款二维码

---

## 💡 提示

- 确保二维码清晰可扫描
- 建议使用 PNG 格式（支持透明背景）
- 图片大小建议控制在 500KB 以内
- 可以使用在线工具压缩图片以减小文件大小

---

**准备好图片后，删除此 README.md 文件即可。**
